プライバシーポリシー

ツール「kidsvid」は、運営者本人が自分の YouTube チャンネルに動画をアップロードし、公開日時を設定するためだけに Google の YouTube Data API を使います。

  • 取得する情報: 運営者本人の YouTube チャンネルの ID・名前と、本人が投稿した動画の情報のみ。
  • 視聴者や第三者の個人情報は取得・保存しません。
  • 認証情報は運営者本人の管理する環境にのみ保存し、第三者に提供しません。
  • Google ユーザーデータの扱いは Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
  • 連携の解除は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも行えます。

お問い合わせ: YouTube チャンネルの概要欄をご覧ください。
