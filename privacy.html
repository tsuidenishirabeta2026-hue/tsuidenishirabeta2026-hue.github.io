プライバシーポリシー

ツール「kidsvid」は、運営者本人が自分の YouTube チャンネル「ぽこぽこひろば」に動画をアップロードし、公開日時を設定するためだけに YouTube API サービスを使います。

kidsvid は YouTube API サービスを使用しています。kidsvid を利用する場合、YouTube 利用規約に同意したものとみなされます。Google によるデータの扱いについては Google プライバシーポリシーをご覧ください。

  • 取得する情報: 運営者本人の YouTube チャンネルの ID・名前と、本人が投稿した動画の ID・公開状態のみ。
  • 利用目的: 動画のアップロード、予約公開の設定と確認、二重投稿の防止。
  • 保存: 投稿した動画の ID と URL を、運営者本人の非公開リポジトリに保存します。視聴者や第三者の情報は取得・保存しません。
  • 共有: 取得した情報を第三者に提供・販売しません。
  • Cookie 等: kidsvid は Cookie や端末情報を保存・読み取りしません。
  • 連携の解除: Google セキュリティ設定のページから、いつでもアクセス権を取り消せます。
  • Google ユーザーデータの扱いは Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

Privacy Policy (English)

kidsvid uses YouTube API Services. By using kidsvid you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy. kidsvid accesses only the operator's own channel ID/name and the IDs and status of videos it uploads, stores only those video IDs/URLs in the operator's private repository, does not collect viewer data, does not share data with third parties, and does not store or read cookies. Access can be revoked at any time via the Google security settings page.
