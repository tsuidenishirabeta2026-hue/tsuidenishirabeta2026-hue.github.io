# SNS 運用（X）

## 目的
- サイト（https://pacific-labo.com）とコラムへの読者を増やす
- 将来の有料 note・定期購読の見込み読者（フォロワー）を集める

## アカウント
- 名前: `パ・リーグ成績ラボ（非公式）`
- ユーザー名の例: `@pacific_labo`（空いていなければ `@pacific_labo_jp` など）
- プロフィール文（案）:
  > パ・リーグ6球団の順位・選手の前年比・移籍の動きを、数字でわかりやすく。毎朝自動更新。非公式のファンサイトです。 https://pacific-labo.com
- アイコン・ヘッダー: 球団ロゴ・選手写真は使わない（権利を確認できないため）。サイト名の文字だけの画像などにする

## 投稿のルール
1. **数字には年と条件を添える**（例: 「2026年・146回」「前年比」「2025年の比較対象の平均」）
2. **Wikipedia や報道記事の文章をそのまま貼らない**。数字（事実）を自分の言葉で書く
3. **球団ロゴ・選手写真・試合映像のスクリーンショットは使わない**
4. **予想・断定をしない**（「来季も活躍する」などは書かない。「注目したい」まで）
5. 選手・球団への悪口、誹謗中傷に反応しない
6. 非公式であることをプロフィールに明記する
7. 有料 note の宣伝は全体の2割以下にする（宣伝ばかりだとフォローされない）

## 投稿の頻度と型
| 型 | 頻度 | 内容 |
|---|---|---|
| コラム紹介 | 新しいコラムを出した日 | 一番面白い数字1つ＋リンク |
| 数字ネタ | 1日1本 | 選手1人の「前年から伸びた指標」など、サイトの選手ページから1つ |
| 移籍・契約 | 動きがあった日 | サイトの移籍・契約ページの出来事を自分の言葉で＋リンク |
| note 紹介 | 週1本まで | 無料部分の要点＋リンク |

時間帯の目安: 朝7〜8時（サイトの自動更新の後）、昼12時台、夜21〜22時。

## 効果の測り方
投稿に貼るリンクには、次の目印を付ける（Google アナリティクスで「X から来た人」を数えられる）:
`?utm_source=x&utm_medium=social`

確認方法: Google アナリティクスの「レポート」→「集客」→「トラフィック獲得」で、「x / social」の行を見る。
