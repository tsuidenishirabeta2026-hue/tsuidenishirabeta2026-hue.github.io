## Wikipedia（CC BY-SA 4.0）の条件

- **根拠**: Wikimedia 財団の利用規約（日本語版）の「再利用」の項。テキストは CC BY-SA 4.0 で、商業目的を含めて再利用できる。
  条件は (1) 記事へのハイパーリンクなどによる帰属表示、(2) ライセンスの表示、(3) 改変した場合はその旨の表示、(4) 改変・追加した文章も CC BY-SA 4.0 で提供すること。
- **自動取得**: API の利用は認められている。禁止されているのは、サーバーに不当な負荷をかける行為など。
  このサイトは1日1回の取得で、選手記事は版番号を確認して、変わった記事だけを50件ずつ取得する。429（アクセス過多）のときは指示された時間だけ待つ。
- **このサイトでの表示**: 各ページに記事名・版番号へのリンク、CC BY-SA 4.0 へのリンク、「記法・脚注の除去など改変あり」を表示している。
- **限界**: 有志が編集する百科事典のため、誤りや更新の遅れがありえる（2026年11月18日時点で、選手記事に2026年の成績が載っているのは約3割）。画面にもそのことを明記している。

### 有料 note での注意（△の理由）

- 順位・勝敗・打率などの**数値そのもの（事実）は著作物ではない**と一般に考えられている。運営者が自分で選んだ切り口・比較・文章で解説する部分は、運営者の著作物として有料で販売できると考えられる。
- 一方、**Wikipedia の文章や表をそのまま、または手を加えて載せる**と、その部分は CC BY-SA 4.0 で提供する義務が生じる。購入者がその部分を自由に再配布できることになり、有料にする意味が薄れる。
- 運用ルール（このリポジトリの記事案もこれに従う）:
  1. Wikipedia の文章・表は有料部分に貼らない。数値は自分で表にまとめ直し、出典として「Wikipedia『○○』（版番号）」を明記する
  2. 独自の比較・解説・指標の組み合わせを有料部分の中心にする
  3. 無料サイトで公開している数値を有料部分で「隠す」ことはしない（同じ数値を元に、解説の深さで差を付ける）
  4. 報道記事の本文は載せない。必要なら引用の要件（必然性、主従関係、出典明記、改変しない）を守る
- 判断が難しい場合は、販売前に専門家（弁護士など）に相談すること。
