# CSV 取り込み形式

このファイルは `node scripts/gen-csv-doc.js` で `src/schema.js` から自動生成しています。

## 置き場所

```
_pllab/data/input/<シーズン>/meta.csv
                             teams.csv
                             standings.csv
                             players.csv
                             batting.csv
                             pitching.csv
                             games.csv            （任意）
                             batting_games.csv    （任意）
                             pitching_games.csv   （任意）
                             splits_batting.csv   （任意）
                             splits_pitching.csv  （任意）
```

- 文字コードは UTF-8（BOM 付きも可）。1行目は列名。列の順番は自由です。
- **空欄は「データなし」**として扱い、0 とはみなしません。記録が 0 の場合は必ず `0` を入力してください。
- 未知の列は警告を出して無視します。
- 選手IDは半角英数字・ハイフン・アンダースコアで、シーズン・移籍・改名をまたいで同じIDを使ってください（同姓同名の区別にも使います）。
- シーズン途中の移籍は、players.csv・batting.csv・pitching.csv に球団ごとの行を分けて入力します（移籍前の行に `to_date`、移籍後の行に `from_date`）。
- 新しいシーズンのフォルダを追加すると、そのシーズンが「最新」として表示されます。過去シーズンのフォルダは残しておくと年度別成績・過去比較に使われます。
- 入力例は `data/input/_template/` と `data/demo/`（デモデータ）を参照してください。
- 球団IDは、パ・リーグ版が F=日本ハム, E=楽天, L=西武, M=ロッテ, B=オリックス, H=ソフトバンク、セ・リーグ版が G=巨人, T=阪神, DB=DeNA, C=広島, S=ヤクルト, D=中日（`config/leagues/` の設定）。下の表の球団IDの一覧は、パ・リーグ版で生成したものです。

## meta.csv（必須）

シーズン情報（key,value の2列）

| 列名 | 内容 | 形式 | 入力 |
|---|---|---|---|
| `season` | 対象シーズン（西暦） | 0以上の整数 | 必須 |
| `as_of_date` | データの基準日（この日の試合終了時点の成績） | 日付 YYYY-MM-DD | 必須 |
| `phase` | 期間区分 | 選択肢: preseason / regular / postseason / offseason | 必須 |
| `champion_team_id` | リーグ優勝が公式に決定した球団ID（未決定なら空欄） | 文字列 | 任意（列ごと省略可） |
| `source_name` | データの出典名（画面に表示） | 文字列 | 必須 |
| `source_url` | 出典URL（任意） | 文字列 | 任意（列ごと省略可） |
| `note` | 注記（任意。画面に表示） | 文字列 | 任意（列ごと省略可） |
| `stats_level` | 個人成績の有無（full=あり／none=取得元に個人成績がない。省略時 full） | 選択肢: full / none | 任意（列ごと省略可） |
| `roster_note` | 所属選手の基準についての注記（任意） | 文字列 | 任意（列ごと省略可） |
| `source_detail` | 出典の詳細（版番号など。「データと分析の方法」に表示） | 文字列 | 任意（列ごと省略可） |

入力例（デモデータより）:

```csv
key,value
season,2026
as_of_date,2026-09-30
phase,offseason
champion_team_id,F
source_name,デモデータ（乱数による架空の試合シミュレーション。実在の成績ではありません）
source_url,
note,デモは交流戦を含まないリーグ内125試合で構成しています。選手名・成績はすべて架空です。
```

## players.csv（必須）

所属選手（1選手1球団1行。シーズン途中の移籍は行を分ける）

| 列名 | 内容 | 形式 | 入力 |
|---|---|---|---|
| `player_id` | 選手ID（シーズン・移籍・改名をまたいで不変） | 文字列 | 必須 |
| `team_id` | 球団ID | 選択肢: F / E / L / M / B / H | 必須 |
| `name` | 登録名 | 文字列 | 必須 |
| `name_kana` | 読み（ひらがな/カタカナ。検索用） | 文字列 | 列は必須（空欄可＝データなし） |
| `number` | 背番号（"00" 等があるため文字列） | 文字列 | 列は必須（空欄可＝データなし） |
| `position` | 守備位置 | 選択肢: 投手 / 捕手 / 内野手 / 外野手 | 必須 |
| `throws` | 投 | 選択肢: 右 / 左 | 列は必須（空欄可＝データなし） |
| `bats` | 打 | 選択肢: 右 / 左 / 両 | 列は必須（空欄可＝データなし） |
| `birth_date` | 生年月日（年齢は基準日で計算） | 日付 YYYY-MM-DD | 列は必須（空欄可＝データなし） |
| `from_date` | この球団への所属開始日（シーズン途中加入時のみ） | 日付 YYYY-MM-DD | 任意（列ごと省略可） |
| `to_date` | この球団の所属終了日（移籍・退団時のみ。空欄=在籍中） | 日付 YYYY-MM-DD | 任意（列ごと省略可） |
| `wiki_title` | Wikipedia 記事名（任意。選手ページからリンク） | 文字列 | 任意（列ごと省略可） |
| `roster_type` | 支配下／育成（任意） | 選択肢: 支配下 / 育成 | 任意（列ごと省略可） |

入力例（デモデータより）:

```csv

p10002,F,山岸 陸,やまぎし りく,35,投手,右,左,1992-11-06,,
```
