# SNS 運用（X）— セ・リーグ版

投稿のルール・頻度・効果の測り方は、パ・リーグ版（`docs/SNS.md`）と同じにする。ここにはセ・リーグ版で違う点だけを書く。

## パ・リーグ版との分け方
- **アカウントは別にする**（パ・リーグ版の @pacific_labo では投稿しない）。note・Google アナリティクスも別。
- 両方のサイトを紹介し合うのは、プロフィールのリンクや固定ポストなど、たまにだけにする（それぞれのファンが読みたいのは自分のリーグの話）。

## アカウント
- 名前: `セ・リーグ成績ラボ（非公式）`
- ユーザー名の例: `@central_labo`（空いていなければ `@central_labo_jp` など）
- プロフィール文（案）:
  > セ・リーグ6球団の順位・選手の前年比・移籍の動きを、数字でわかりやすく。毎朝自動更新。非公式のファンサイトです。 https://centrallabo.com
- アイコン・ヘッダー: `docs/central/sns/icon.png`（1000×1000）・`header.png`（1500×500）。文字と図形だけで作っており、球団ロゴ・選手写真は使っていない。
  元の SVG も同じ場所にある（パ・リーグ版と区別できるよう緑系の色）
- note のヘッダー: `docs/central/sns/note-header.png`（1280×670。note の見出し画像の比率に合わせ、文字を中央に寄せてある）

## 効果の測り方
投稿に貼るリンクには、パ・リーグ版と同じく `?utm_source=x&utm_medium=social` を付ける。
セ・リーグ版の Google アナリティクス（パ・リーグ版とは別のプロパティ）の「レポート」→「集客」→「トラフィック獲得」で「x / social」の行を見る。

## ハッシュタグ
毎回 `#セリーグ` `#プロ野球` を付け、選手・球団の話題ならその球団のタグも足す（1投稿に2〜3個まで）。
- 全体: `#セリーグ` `#プロ野球`
- 球団（例。**使い始める前に、各球団の公式アカウントが実際に使っているタグを確認して差し替える**）:
  巨人 `#巨人`／阪神 `#阪神タイガース`／DeNA `#baystars`／広島 `#carp`／ヤクルト `#swallows`／中日 `#dragons`

## 投稿の下書き
数字を使う投稿の下書きは、サイトのデータ（Wikipedia の年度別成績などから再計算した値）と照合してから書く。
有料 note の宣伝を含む下書きや有料部分は、この公開リポジトリには置かず、非公開リポジトリに置く（パ・リーグ版と同じ）。
