# 平良海馬はなぜ「先発で防御率1.36」を出せたのか──2023年の先発との違いを数字で比べる

**対象**: 埼玉西武ライオンズ 平良海馬（投手・背番号61）
**比較**: 2023年（先発・150.0回）と 2026年（先発・146.0回）

2026年、平良海馬投手は主に先発として146回を投げ（23登板のうち22試合に先発）、防御率1.36で最優秀防御率のタイトルを獲得しました。ゴールデン・グラブ賞（投手部門）と、3・4月の月間MVPも受賞しています。

平良投手が本格的に先発を務めたのは、今回が2度目です。1度目の2023年も防御率2.40と好成績でしたが、2026年はそこからさらに1点以上よくなりました。2つの先発シーズンを並べると、何が変わったのかが見えてきます。

## 1. 救援と先発を行き来してきた8年間

| 年 | 主な役割 | 登板 / 先発 | 投球回 | 防御率 | セーブ / ホールド |
|---|---|---|---|---|---|
| 2020 | 救援 | 54 / 0 | 53.0 | 1.87 | 1 / 33 |
| 2021 | 救援 | 62 / 0 | 60.0 | 0.90 | 20 / 21 |
| 2022 | 救援 | 61 / 0 | 57.2 | 1.56 | 9 / 34 |
| 2023 | **先発** | 23 / 23 | 150.0 | 2.40 | 0 / 0 |
| 2024 | 先発・救援 | 22 / 5 | 48.2 | 1.66 | 0 / 9 |
| 2025 | 救援（抑え） | 54 / 0 | 52.2 | 1.71 | 31 / 8 |
| 2026 | **先発** | 23 / 22 | 146.0 | **1.36** | 0 / 0 |

救援だった2020〜2022年と2025年は、いずれも防御率0〜1点台でした。先発に回った2023年は、それより1点ほど高い2.40でした。2026年は、先発でも救援時代と同じ水準の数字を出したことになります。

## 2. 2023年と2026年の比較

| 指標 | 2023年（先発） | 2026年（先発） | 変化 |
|---|---|---|---|
| 投球回 | 150.0 | 146.0 | ほぼ同じ |
| 防御率 | 2.40 | 1.36 | −1.04 |
| WHIP（1回あたりの走者） | 1.13 | 0.96 | −0.17 |
| 奪三振率（9回あたり） | 9.18 | 8.69 | −0.49 |
| **与四球率**（9回あたり） | **3.30** | **2.77** | −0.53 |
| **被本塁打率**（9回あたり） | **0.60** | **0.25** | −0.35 |
| K/BB（奪三振÷与四球） | 2.78 | 3.13 | +0.35 |

被本塁打率は、被本塁打×9÷投球回で計算しています（2023年は10本、2026年は4本）。

**読み取れること（解釈）**
- 三振を奪う力（奪三振率）は、2023年からむしろ少し下がっています。
- 一方で、**四球と本塁打がはっきり減りました。** 特に被本塁打は、ほぼ同じ投球回で10本から4本に減っています。
- 三振で圧倒する形から、「四球で走者を出さず、長打を打たれない」形に変わったことが、防御率の改善につながったと数字からは読めます。

## 3. 比較対象の平均との差（2025年）

2026年は選手記事の更新がまだ揃っていない（更新率40%）ため、平均と比べられる最新の年は2025年です。参考として、2025年の平均と2026年の平良投手を並べます。

| 指標 | 平良（2026年） | 比較対象の平均（2025年） |
|---|---|---|
| 防御率 | 1.36 | 2.96 |
| WHIP | 0.96 | 1.21 |
| 奪三振率 | 8.69 | 7.36 |
| 与四球率 | 2.77 | 2.66 |
| 被本塁打率 | 0.25 | 0.65 |

比較対象は「現在パ・リーグ6球団に所属する投手147人の、2025年のパ・リーグでの成績の合計」です。退団・引退した選手は含まれないため、公式のリーグ平均とは異なります。年も違うため、目安として見てください。

与四球率は平均並みですが、被本塁打率は平均の半分以下です。

## 4. これから注目したい点

- **西武は10月30日にポスティングによるMLB移籍を容認し、11月2日に申請の手続きを行ったと発表しています。** 交渉の行方によって、来季の舞台が変わる可能性があります。
- 被本塁打率0.25は、平良投手自身のこれまでの先発シーズン（2023年 0.60）と比べても突出して低い数字です。本塁打は試合ごとの偶然にも左右されやすいため、来季この水準がどこまで続くかが一つの注目点です。
- 与四球率2.77は、2022年（2.81）と並んでキャリアで最も良い水準です。この制球が続くかどうかにも注目です。
